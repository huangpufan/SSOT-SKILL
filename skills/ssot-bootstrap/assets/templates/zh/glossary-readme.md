当一个仓库词会改变你对需求、状态、角色、边界或记录的理解时，使用本页。找到
准确术语，打开它的条目，行动前回答三个问题：它在这里的正面含义是什么，为什么
这个区分重要，哪个相近情况不成立。

这里的“所有者（owner）”是一条事实唯一被解释和维护的位置，不一定指某个人。
Q01-Q21 是 STATUS 中二十一类质量、风险与治理检查编号，不是评分。术语条目只解释
这些检查涉及的仓库用词；检查的适用性和事实路线仍由 STATUS 登记表负责。

例如，一个仓库可能用“就绪”描述用户看到的对象，也用它描述服务健康；两种含义
不能互换。分别打开两个术语条目，对照例子与反例，再跟随每个词链接的唯一产品、
架构、流程或记录所有者。

每个术语条目都用平实语言说明定义、它改变的决定、一个具体例子、一个反例或
常见误解、唯一所有者与证据、相关术语、规范拼写、别名/缩写、用户标签、机器
token（程序使用的固定值）、翻译约束、适用范围，以及什么变化会使定义失效。
条目还要说明术语处于使用中（`active`）、已弃用（`deprecated`）还是已退休
（`retired`）；不再使用时写明替代词和迁移方向。覆盖适用 Q01-Q21
词汇，但不要在这里解释 Q 协议本身。尤其检查隐私/数据治理标签、安全与申诉
用词、公平或解释承诺、生命周期/退役状态、输出质量或漂移标签，以及价格/套餐/
权益用词：读者在委托改动前必须知道它们在本仓库的含义。
下面的术语家族清单是唯一术语清单。它负责找到条目，不再另建按字母或旧协议
分类的第二份清单。条目所有者可以是独立术语文件，也可以是本 README 或主题
文件中的唯一术语二级标题锚点。

## 术语家族覆盖

精确处理下列六个家族。这张表就是有限完整清单：每个真实术语条目必须且只能在
一个家族中链接一次，不得再复制到第二份索引。只有源码、数据结构、产品、架构、
流程、记录或根说明真实使用某个仓库专用词时，对应家族才适用；没有时写明查过
什么，以及哪类变化会触发复核。不要为了填表虚构术语。

只有最后一格链接了这个家族的每个真实术语所有者，才能写 `applicable`（适用）。
空家族写 `not_applicable`（不适用），并在最后一格使用：`原因=<具体理由>；
已检查=[证据所有者](<可解析路径>)；复核条件=<可观察事件>。` 所有占位内容都要
替换成仓库事实。

| 术语家族 | 发现条件 | 处理 | 条目所有者链接或原因 |
|---|---|---|---|
| 产品与用户概念 | 存在仓库专有的用户角色、问题、承诺、能力、旅程、套餐、权益或可见标签。 | applicable / not_applicable | |
| 架构与运行时概念 | 存在具名运行时所有者、组件/领域、代理角色、部署单元、契约、资源或技术边界。 | applicable / not_applicable | |
| 状态、生命周期与工作流术语 | 存在持久状态、状态变化、工作流结果、记录状态或仓库专有生命周期标签。 | applicable / not_applicable | |
| 信任、身份、访问与数据治理术语 | 存在具名身份、角色、权限、租户/工作区边界、数据类别、同意、隐私或治理标签。 | applicable / not_applicable | |
| 证据、验证与运行操作术语 | 存在仓库专有门槛、证据层级、信号、服务目标、运行操作标签、规则家族或规则放置层级。 | applicable / not_applicable | |
| 并发控制术语 | 存在具名队列、租约、锁、调度键、配额键或并发限制。 | applicable / not_applicable | |

`applicable` 表示本仓库确实使用这一家族的专用词，必须链接条目；
`not_applicable` 表示确实没有，并要在同一行写明原因、检查证据和复核条件。

## 新增或修改术语

只有仓库真实使用一个专有或被重定义的词时，才创建术语条目。可以使用独立
`glossary/<term>.md` 文件，也可以使用本 README/主题文件中的唯一二级标题锚点。先写
正面定义，再说明误解会改变什么决定，给真实例子和最近反例，链接一个权威所有者
及合适的代码、数据结构、决策或测试证据，最后在唯一术语家族清单中链接一次。

不要仅为迎合清单形状而拆散一份仍然好读的主题页。条目超过 30 条，或横跨多个
需要独立所有权和维护的业务领域时，再拆成独立文件。

枚举、数据结构、产品承诺、架构契约、流程规则或决策改变含义时，更新
术语条目和所有依赖旧区分的消费者。两个条目声称同一定义时，选择一个所有者，
另一个改成相关术语链接。

## 边界，以及何时重新检查

本术语表只记录仓库专有语言，或在这里有特殊含义的通用词。它不教授一般框架
词汇，也不替代产品、架构、流程或记录所有者。术语新增、改名、合并、拆分或退休
时复核索引；所有者、证据、范围或失效触发条件变化时复核条目。
