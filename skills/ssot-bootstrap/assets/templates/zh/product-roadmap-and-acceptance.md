## 怎样知道长期使用仍有价值

一次交互成功还不够。这里只保留少量结果指标和反向指标，用来判断目标人群在
重复真实任务中是否持续受益，同时不能掩盖放弃、返工、等待、信任下降或伤害。
每个指标都要写清“具体算什么、观察谁、看多长时间、从哪里取数”。没有匹配证据
前，当前基线必须写 `unknown`（未知），不能把估计包装成事实。

| | outcome / counter-metric | 分子、分母、排除项与单位 | | 单任务 / 滚动 7 天 / 滚动 30 天 / 发布批次 / 其它 | 事件、问卷、支持记录、验收产物或 `missing`；写明目的、最少采集、访问、保留期与禁止内容 | unknown — 尚无匹配基线证据 | 达到阈值、持续变化或评审事件后，要改变哪项产品决定 | |
