## 按当前运维路径执行

<!-- 先用连贯文字解释安全顺序，再给精简步骤。写清前置条件、环境与
     tenant/workspace 范围、配置来源、持久副作用、依赖，以及无法自动撤回的
     分界点。 -->

1. 从可信信号确认环境、受影响范围、操作者身份和当前症状。
2. 改状态前，检查所链接的运行时所有者，以及当前事故、维护或发布背景。
3. 执行最小的已授权动作，并保留关联 ID 或证据指针。
4. 分别验证用户可见结果与系统信号。
5. 不满足验收条件时，恢复、回滚或升级处理。
