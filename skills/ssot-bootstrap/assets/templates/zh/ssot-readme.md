## 不变量

这里登记的是人定下、实现必须守住的规则。agent 不能自行改变规则的含义、
范围或状态：任务如果和 confirmed 的规则冲突，要先停下来问用户。candidate 的规则
是推断出来的，还在等用户确认：先当作强默认遵守，任务涉及它时要说出来。

| ID | 类型 | 规则 | 解释位置 | 状态 | 来源 |
